# Micnic Shopify Theme

Custom Online Store 2.0 starter theme inspired by the attached Micnic mobile and desktop references.

## Included

- Editorial homepage hero
- Desktop mega menu + mobile drawer
- Category promo tiles
- Split lifestyle/story section
- Featured collection product rail
- Value props strip
- Styled product template with gallery, option pills, payment buttons, and accordions
- Styled collection template with banner, tag chips, sorting, and product grid
- Newsletter strip and dark editorial footer

## Next steps

1. Upload the `themes/micnic` folder as a Shopify theme or connect it with Shopify CLI.
2. Add real menus in Shopify admin and assign them to the header/footer.
3. Replace placeholder content with Micnic photography and collections.
4. Fine-tune the section settings directly in the theme customizer.
